AutoClipper

AutoClipper membantu mempercepat proses clipping video YouTube menjadi konten pendek. Seluruh proses menggunakan Google Gemini API (Free Tier) dan Google Colab milikmu sendiri, sehingga saat ini dapat digunakan tanpa biaya. Ikuti langkah-langkah di bawah untuk mulai membuat klip.

Masukkan video & API key
02Klip yang ditemukan
Hapus centang kalau ada klip yang mau dilewati.
03Buat notebook
Crop otomatis ngikutin wajah pembicara. Klip yang mau diatur manual bisa di-set lewat tombol "Atur crop manual" di daftar klip di atas.
Cara pakai
  1. Isi API key & link video, klik Analisis video.
  2. Cek daftar klip yang muncul, hapus centang yang tidak perlu.
  3. Pilih mode lalu klik Unduh notebook Colab — file .ipynb otomatis terdownload.
  4. Buka colab.research.google.com → File → Upload notebook → pilih file yang barusan terdownload.
  5. Klik Runtime → Run all, izinkan akses Google Drive saat diminta, lalu tunggu sampai selesai.
  6. Hasil klip ada di folder AutoClipper_Output di Google Drive kamu.
Notes

Ini hanya tools yang membantu dan mempermudah proses clipping. Jika ingin hasil yang lebih sempurna, kamu masih bisa mengedit hasilnya sendiri.
